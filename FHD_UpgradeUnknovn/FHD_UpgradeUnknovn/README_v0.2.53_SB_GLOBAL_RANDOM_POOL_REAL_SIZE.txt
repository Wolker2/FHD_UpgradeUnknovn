FHD_UpgradeUnknovn v0.2.53 - SB GLOBAL RANDOM POOL + REAL SIZE

Изменения:
- Стоимость обслуживания удалена из новой генерации СБ.
- Все не-корпусные свойства теперь находятся в общем пуле и могут выпасть на любом оборудовании без привязки к его типу.
  Пример: дальность захвата может выпасть на радаре, скорость двигателя на ГЗП, бонус сканера на оружии и т.д.
- Корпусная группа остаётся исключением: Броня корпуса и Снижение массы корабля доступны только дроиду и генератору защиты.
- На одном предмете может быть максимум одно корпусное свойство, и оно не гарантировано.
- Сопротивление урону от астероидов по-прежнему не генерируется.
- Уменьшение размера теперь реально меняет ItemSize предмета, поэтому уменьшается занимаемая масса/место в трюме.
- Надёжность реализована как увеличение эффективного ресурса до поломки через уменьшение износа. Движок жёстко ограничивает ItemDurability значением 100%, поэтому стандартный максимум в карточке не может стать 120/120 обычным скриптом.
- СБ I: всегда 3 разных свойства; 5% шанс на 4-5. СБ II: 2. СБ III: 1.
- Цвета СБ сохранены: I фиолетовый, II синий, III зелёный, редкий I коричневый.

Совместимость:
Служебные определения старого свойства стоимости оставлены внутри Lang только для безопасной загрузки уже созданных предметов из предыдущих версий, но новые СБ его больше никогда не выбирают.
