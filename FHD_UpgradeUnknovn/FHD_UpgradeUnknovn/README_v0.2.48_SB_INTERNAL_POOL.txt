FHD_UpgradeUnknovn v0.2.48 - SB INTERNAL POOL

Главное изменение:
- уровни MM I / MM II / MM III больше не показываются как результат исследования; используется единая метка СБ (Скрытый Бонус);
- исследование больше НЕ выбирает случайный микромодуль из общей таблицы MicroModuls;
- новые СБ формируются только из собственного внутреннего списка FHD_UpgradeUnknovn; установка/удаление EvoMM, ShuMM, Cat_MM, LEOMMMod и других пакетов ММ не меняет пул новых СБ.

Правила числа свойств:
- 60% успешных СБ: 1 свойство;
- 25%: 2 разных свойства;
- 15%: 3 разных свойства;
- для 3-свойственного результата действует 5% шанс расширения до 4-5 разных свойств (если тип оборудования поддерживает столько свойств).

Универсальные свойства для любого обычного оборудования:
- броня/корпус;
- сопротивление урону от астероидов;
- снижение массы корабля.

Специализированные свойства выбираются только для подходящего типа: бак, двигатель, радар, сканер, дроид, захват, ГЗП и соответствующий класс оружия.
Значения каждого свойства генерируются из внутренних диапазонов слабой/средней/мощной группы; эти группы используются только для расчёта и игроку отображаются как СБ.

Обычные устанавливаемые ММ1/ММ2 после исследования остаются отдельной механикой v0.2.47 и не являются СБ.
