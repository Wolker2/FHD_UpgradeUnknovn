# FHD_UpgradeUnknovn 0.4.23 — Final Balance (Nexus-style)

**Отдельная новая папка для точной версии, предоставленной пользователем.** Существующие версии 0.2.89, 0.4.16, 0.5.1 и другие папки GitHub не заменяются. Версия 0.4.23 — историческая ветка/баланс из предоставленного архива, а не объявление о том, что это последняя версия.

## Готовый мод

Оригинальный **RAR5**: [`install/FHD_UpgradeUnknovn-0.4.23-Final Balance.rar`](install/FHD_UpgradeUnknovn-0.4.23-Final Balance.rar), 39382 байт, SHA-256 `efba9c536ca3b126d3dea4340f8d27d45c052c73ee2e7fc6328fcfe35b0b6eed`. Содержит **8 игровых файлов** в `Mods/FHD_MODS/FHD_UpgradeUnknovn/`.

## Редактируемые исходники и инструменты

- `source/config/`: **4 DAT** полностью расшифрованы в редактируемые JSON (включая строки и встроенные игровые скрипты); обратная сборка всех четырёх проверена побайтово.
- `source/graphics/2FHDUU_DualMM.json`: полные команды GI-изображения типа 2; обратная сборка проверена побайтово.
- `source/module/ModuleInfo.txt`: оригинальный UTF-16LE с BOM представлен в UTF-8; сборка восстанавливает исходные байты.
- `scripts/dat_codec.py` и `scripts/gi_codec.py`: автономные кодеки редактируемых DAT/GI.
- `scripts/build.py`: пересобирает установочный ZIP; **не** меняет установленную игру.
- `tests/verify.py`: контролирует SHA-256 всех 8 игровых файлов и обратную сборку редактируемых ресурсов.
- `original-file-sha256.json`: SHA-256 и размеры оригинальных игровых файлов.

### Важно: ограничение исходников DLL/SCR

В присланном RAR находятся только **скомпилированные** `FHDUUCore.dll` и `FHDUU_Dialog.scr`, **без** оригинальных исходников C/ASM и RSON. Эти два файла сохранены в `payload/` и включаются в устанавливаемый ZIP без изменения. Нельзя считать данный набор полной исходной реализацией DLL и диалога. Проверка исходников не означает, что DLL не использует хуки, EXE-адреса или обеспечивает совместимость обоих EXE. Этот вопрос требует отдельной проверки.

## Сборка и проверка

Требуется Python 3.10+ (только стандартная библиотека); исходный RAR и игра не нужны для новой сборки.

```sh
python3 tests/verify.py
python3 scripts/build.py --verify-original
```

Выход: `dist/FHD_UpgradeUnknovn_0.4.23_Final_Balance_INSTALL.zip`, **8 файлов**. При осознанных изменениях исходников убрать `--verify-original`: эта опция только для проверки полного совпадения с исходником.

Реальная загрузка в игре, сохранения, работа на старом/новом EXE, конфликты с QuestMarker, баланс и устранение накопления бонусов **не проверены** во время этого импорта. TEST/RELEASE статус не подменялся. Данное действие **не меняет игровой код**, а только сохраняет версии и восстанавливает конфигурации.
