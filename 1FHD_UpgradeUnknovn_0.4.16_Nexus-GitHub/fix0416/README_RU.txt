FHD_UpgradeUnknovn 0.4.16 NATIVE SCIENCE TEST

Основа — повторно приложенная пользователем рабочая 0.4.13 «рабочий вариант 2 ОПЕРА(1)». Исправления из 0.4.14/0.4.15 в установочный архив не переносятся. Счётчика улучшений нет, FHDUU_NoRepeatMark не меняется.

Добавлен допуск исследованного предмета к штатному улучшению научной базы после СБ, с одним или двумя обычными ММ. Решение о стандартных/уже улучшенных характеристиках принимает исходный CanImprove/HasStandardStats. На локальной копии исходным игровым снятием ММ исключаются оба обычных ММ и вычитаются только явно отмеченные уже физически внесённые СБ. Реальный предмет, его ММ, свойства и значения при проверке не меняются. Для баков с СБ размера учитываются допустимые исходные целые размеры, поскольку исходный скрипт СБ уменьшает размер с целочисленным усечением; проверяет их тот же штатный CanImprove.

Изменён только пятибайтовый вызов допуска внутри списка оборудования научной базы в памяти EXE. Общий CanImprove, остальные его вызовы, денежные проверки, цена, списание оплаты, вызов виртуального Improve, фактические прибавки и обновление параметров корабля остались исходными. После штатного улучшения повторный допуск закрывает исходное сравнение характеристик; отдельного состояния «улучшено» не добавляется.

Исходный код/данные рабочего ядра, текста и отображения двух иконок сохранены побайтно. Защитная обёртка запуска сохраняет EBX/ESI/EDI вокруг исходного установщика иконок, в котором локальные переменные перекрывали сохранённые регистры. Новый код дописан в ту же страницу DLL без изменения старой таблицы перемещений, числа секций и размера отображения. Указатель экспортного запуска перенаправлен на обёртку.

В установочном архиве семь файлов. Заменена только FHDUUCore.dll. Оба Lang.dat, Main.dat, CacheData.dat, FHDUU_Dialog.scr и ModuleInfo.txt побайтно сохранены. Поэтому версия/описание в менеджере модов остались прежними.

Проверки в x86-эмуляции: оба EXE; отсутствие СБ, СБ и 0/1/2 ММ; типы оборудования 42..68, баки с изменением размера; реальный нативный Improve и запрет повторного улучшения; неизменность предмета и всех записей свойств при проверке допуска. Для станционного пути проверены реальный переход отбора, цена/списание оплаты, отсутствие денег, штатное улучшение и повторный отказ. Для нового EXE проверены обе строки ММ и исходный обработчик второй иконки до/после улучшения, снятия и возврата ММ2. В исходной 0.4.13 две иконки адаптированы только к новому EXE; эту привязку не меняли.
