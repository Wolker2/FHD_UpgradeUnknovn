# FHD_UpgradeUnknovn 0.5.1 — новая версия (архив + частично восстановленные исходники)

Архив `install/FHD_UpgradeUnknovn_0.5.1.zip` сохранён полностью и побайтово, SHA-256 `fcae201d861a1cfdf7091cb949c18c344f9c3c674594725bcf1ddd4888ea0e63`.

`python scripts/recover.py` извлекает **4 DAT и 1 GI** в редактируемый JSON с точной обратной сборкой. После изменения `source/` скрипт `python scripts/build.py` собирает установочный ZIP. **Это частичное восстановление**, не исходники DLL/SCR и не подтверждение безхуковой реализации или полной совместимости EXE. Статус в реальной игре не проверен. Все прежние версии на GitHub сохранены.
